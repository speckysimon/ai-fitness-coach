## How to Use

### For Users:
1. **Refresh your browser** (Cmd+R / Ctrl+R)
2. **Open Theme Selector** in the sidebar (palette icon)
3. **Click on any theme** to try it out:
   - Mountain Meadow for fresh greens
   - Oceanic Voyage for calming blues
   - Yellow Sunset for energetic warmth
4. **Toggle light/dark mode** to see both variants

### For Admins:
1. Go to **Admin Panel → Theme Configuration**
2. See all 6 themes with full color palettes
3. **Edit colors** if needed
4. **Set as Active** to make it the default for all users
