# RiderLabs — Mission Statement

**Last Updated:** February 21, 2026  
**Version:** 3.0

---

## Mission

**Engineering race-day performance through deterministic, stream-backed analysis.**

RiderLabs turns raw training data into race-context performance intelligence — identifying limiters and guiding the next training block with deterministic logic.

---

## What RiderLabs Is

RiderLabs is a **race-aligned performance intelligence engine**.

Not a dashboard.  
Not a load tracker.  
Not a generic AI plan generator.

It answers two questions:

1. **Why did this race go the way it did?**
2. **What do I change next block because of that?**

Everything else is subordinate to those two questions.

---

## What Makes It Different

### Deterministic, Not Probabilistic

Every metric — power zones, durability, HR drift, variability index, fade — is computed from raw stream data using reproducible, versioned algorithms. No AI guessing. No black boxes. The same input always produces the same output.

### Stream-Backed Analysis

Raw power and HR time-series are stored server-side and processed directly. This enables real coaching diagnostics that summary metrics hide: fade across thirds, stochasticity, repeat hard efforts, HR decoupling. Without streams, you're metric-rich but behaviour-blind.

### Race-Context Limiter Detection

The limiter engine identifies *why* performance is capped — not just *what* the numbers are. Acceleration repeatability, threshold under stress, late-race resilience, VO2 ceiling, exposure sensitivity. Each limiter is traced to stream evidence from race-tagged activities.

### Stable Thresholds

FTP and FTHR are persisted server-side with explicit source and confidence. Manual values are never silently overwritten. All analytics — normalisation, durability, stress classification, limiter detection — resolve from a single canonical source.

## Target Athlete

Competitive amateur cyclists (cat 3–5, gran fondo, gravel racers) who:
- Train with a power meter
- Race seriously
- Want structured, data-backed coaching without a €200/month coach

---

## Core Values

### 1. Determinism Over Heuristics
Calculations are reproducible and source-tracked. If a number changes, there's an explicit reason.

### 2. Race Context First
Every feature is evaluated against whether it helps answer the two core questions. Features that don't serve race performance are deprioritised.

### 3. Explainability
Recommendations reference the specific evidence that produced them. Athletes understand *why*, not just *what*.

### 4. Minimal Surface Area
A focused tool that does one thing exceptionally well beats a sprawling platform that does many things poorly.
